# مرجع کامل ESP32 (ESP-WROOM-32) برای توسعه سخت‌افزاری و نرم‌افزاری برد IX4

> هدف این سند: همه چیزی که برای کدنویسی/توسعه روی برد «Esp32 IX4 Relay Board» لازم است، بدون مراجعه به جای دیگر.
> منابع: دیتاشیت Espressif ESP32-D0WDQ6 و ESP-WROOM-32 + مشخصات رسمی برد (iranicboard.ir).

## ۱) هسته و ماژول

| مشخصه | مقدار |
|---|---|
| تراشه | ESP32-D0WDQ6 (دو هسته Xtensa LX6، تا 240MHz) |
| SRAM | 520KB (+16KB RTC) |
| ROM | 448KB |
| فلش روی ماژول | 4MB (WROOM-32؛ بعضی نسخه‌ها 8/16MB) |
| رادیو | WiFi 802.11 b/g/n @2.4GHz + Bluetooth v4.2 BR/EDR و BLE |
| آنتن | پی‌سی‌بی مسی (meander) روی ماژول + فضای keepout |
| ولتاژ منطقی | **3.3V** (پایه‌ها 5V-tolerant نیستند) |
| تغذیه ماژول | 3.0–3.6V پایدار؛ متوسط ~80mA، **پیک TX ~310mA**؛ تغذیه را ≥500mA طراحی کنید |
| خواب عمیق | ~10µA |
| چیدمان شیلد | شیلد فلزی، خروجی کاستلیشن دوطرفه ۱۶+۱۶+۵ |

## ۳) قوانین طلائی پایه‌ها

- **GPIO 34/35/36/39:** فقط ورودی‌اند و پول‌آپ/پول‌داون داخلی ندارند.
- **GPIO9..11 (و 6..8):** فلش — هیچ‌وقت استفاده نکنید.
- **ADC2 کلاً با WiFi تداخل دارد**؛ برای آنالوگ از ADC1 (GPIO32–39) استفاده کنید.
- **در لحظه بوت:** GPIO0=HIGH، GPIO2=LOW/شناور، GPIO15=LOW(برای سکوت لاگ)، GPIO12=LOW، GPIO5 هر چیزی.
- **GPIO2 و GPIO12 روی برد، رله هستند:** ترانزیستور/مقاومت بیس آن‌ها را نزدیک صفر نگه می‌دارد و بوت سالم می‌ماند؛ ولی هنگام پروگرام هم اگر مدار خارجی به GPIO2/12 وصل است احتیاط کنید (هشدار رسمی فروشگاه هم همین است).
- جریان هر GPIO: منبع/سینک ایمن ≈ 12mA (حداکثر ~40mA).

| رابط | پایه‌های پیشنهادی |
|---|---|
| I2C | SDA=21, SCL=22 |
| SPI (VSPI) | SCK=18, MISO=19, MOSI=23, CS=5 |
| UART2 | RX=16, TX=17 |
| PWM (LEDC) | هر GPIO خروجی؛ رله‌ها ۴/۲/۱۳/۱۲ اشغال‌اند → از ۱۴/۱۵/۲۵/۲۶/۲۷/۳۲/۳۳ استفاده کنید |

| ADC امن با WiFi | ADC1: GPIO32–39 |

## ۵) نکات Arduino Core (v2.x/v3.x)

- برد: `ESP32 Dev Module`؛ پورت همان مجازی CH340 (115200 بود برای پروگرام استاندارد).
- در Arduino پین‌ها با شماره GPIO نام‌گذاری می‌شوند (نه شماره پین ماژول).
- `pinMode(34, INPUT)` درست ولی `INPUT_PULLUP` برای 34–39 تعریف‌نشده (سخت‌افزار ندارد).
- `analogRead` پیش‌فرض ۱۲بیت/~۳٫۳V با `analogSetAttenuation(ADC_11db)`.
- PWM: با core جدید `ledcAttach(pin, freq, res)` + `analogWrite(pin,val)`.
- کتابخانه‌های پرکاربرد: `WiFi.h`, `WebServer.h` / `ESPAsyncWebServer` (دمو رسمی ایرانیک هم با همین + WebSockets است), `PubSubClient` (MQTT), `ArduinoJson`, `PubSubClient`/`BluetoothSerial`.
- OTA: `ArduinoOTA.h` یا کتابخانه `WebUpdate`.
- Deep sleep: `esp_sleep_enable_timer_wakeup()` + `esp_deep_sleep_start()` — توجه: رله‌ها در این حالت وضعیت‌دار نیستند و روشن ماندنشان به مدار بستگی دارد (ترانزیستور حفظ وضعیت نمی‌کند → رله خاموش می‌شود).

## ۷) زنجیره تغذیه برد (از روی عکس + پشتیبانی فروشگاه)

```
جک ۱۲V (DC005) ── دیود حفاظت ──► LM2596-5.0 (باک، سلف بزرگ سفید۱) ──► +5V ──► AMS1117-3.3 ──► ESP32
                                   │
                                   └── مسیر رله‌ها: بوبین ۱۲V مستقیم از +12V
```
- سلف سفید دوم روی عکس: هنوز عملکردش از عکس قطعی نیست — در شماتیک با خط‌چین «احتمالاً فیلتر ورودی یا باک دوم» آمده و باید روی نمونه فیزیکی چک شود.
- منبع پیشنهادی فروشگاه: 12V / ≥1A (چهار رله‌ی هم‌زمان + WiFi یکجا < 0.5A می‌شود اما 1A حاشیه‌ی امن سازنده است).
- USB فقط برای پروگرام/دیباگ 5V می‌دهد → **رله‌ها بدون جک 12V روشن نمی‌شوند** (هشدار رسمی).
- ممنوع: اتصال مستقیم 24V به ورودی (فروشگاه مبدل 24→12 توصیه کرده).

## ۸) امنیت و نکات برق شهر

- رله‌ها JQC-3F(T73)-DC12V، کنタクト 10A/250VAC (فروشگاه 7A@220VAC برای بار مقاومتی اعلام کرده؛ برای القایی/موتور جریان راه‌اندازی را ضریب‌دار حساب کنید).
- ترمینال وسط COM است؛ ترتیب NO/NC روی نمونه با مولتی‌متر چک شود (هشدار رسمی فروشگاه).
- برد ایزوله نیست: محفظه عایق + فیوز + فاصله خزشی ≥ 6mm الزمی.
